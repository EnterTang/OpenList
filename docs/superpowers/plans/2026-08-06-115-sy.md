# 115-sy Behavior-Compatible Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a native Go `115-sy` OpenList driver that independently reproduces the observable Symedia 115 mount, transfer, upload, and automation behavior without importing the existing `115driver` client.

**Architecture:** Register one `115 SY` driver under `drivers/115_sy`. Keep the network protocol, authentication, throttling, response decoding, upload, share, offline, and automation code in `internal/115sy`; expose storage operations through OpenList driver interfaces and extended operations through the existing `Other` and offline-download integration points. Existing `drivers/115`, `drivers/115_open`, and `drivers/115_cd2` remain untouched except for additive registry/settings wiring.

**Tech Stack:** Go 1.25/1.26 toolchain, standard `net/http`, `net/http/cookiejar`, `crypto/*`, `encoding/json`, existing `golang.org/x/time/rate`, `github.com/aliyun/aliyun-oss-go-sdk/oss`, `pkg/cron`, `internal/model`, `internal/driver`, and `pkg/utils`. Do not add a new module dependency and do not import `github.com/SheltonZhu/115driver` or `github.com/OpenListTeam/115-sdk-go` from the new driver.

---
